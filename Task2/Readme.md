# 🎵 ARIRANG Music Player

A clean, browser-based music player built with **HTML, CSS, and JavaScript** as Task 2 of the [CodeAlpha](https://www.codealpha.tech/) Frontend Development Internship.

---

## 📸 Preview

> A music player themed around the ARIRANG tracklist, featuring album artwork, playback controls, and a song progress bar.

---

## ✨ Features

- 🎧 Play / Pause audio playback
- ⏭️ Next and Previous track navigation
- 📊 Real-time progress bar with current and total duration display
- 🖼️ Dynamic album cover art
- 📋 ARIRANG tracklist with clickable song selection
- 📱 Responsive design — works on desktop and mobile

---

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Structure and audio element |
| CSS3 | Styling and responsive layout |
| JavaScript | Playback logic, DOM manipulation |

## 🚀 Getting Started

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/khwaaishpatwa2110/codealpha-tasks.git
   ```

2. Navigate to the Task2 folder:
   ```bash
   cd codealpha-tasks/Task2
   ```

3. Open `index.html` in your browser — no build step or server required.
